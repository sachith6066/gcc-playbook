# The GCC Architect's Playbook

A field reference for building and running a Global Capability Centre in India — strategy,
build sequence, unit economics, compliance, transfer pricing and failure modes.

Every figure is marked for how far it can be trusted. In October 2026 twenty-four claims from
this playbook were put through multi-source research with three-vote adversarial verification;
thirteen were killed. What survived and what did not is documented in the final section.

Corrections and better sources are welcome — particularly on the thirteen cost items that have
no surviving independent source. Open an issue, or email sachith@recruiseglobal.com.
